平台风控与发布规则速览
  • 草稿自动化：已配置 AppID/Secret 时，服务直接走微信官方 API 上传素材建草稿，再由 Playwright 发表；
  • 留言开关：官方 API 草稿固定自动开启留言 (`need_open_comment=1`)；
  • 群通知关闭：网页端发表前自动关闭“群发通知 / 发送群通知”，静默发表不扰民；
  • 人工安全确认：若微信后台要求扫码确认，任务自动进入 `waiting_manual_confirm`，仅轮询结果，绝不重复点击。
  • 标题长度：小红书标题严格限制在 20 字符以内，超长会被平台拦截；
  • 图片张数：图文笔记图片张数严格限制在 1 ~ 18 张 之间；
  • 封面规格：推荐采用 3:4 竖版动态排版大图；
  • 防风控间隔：发布器强制实行 1800 秒（30分钟） 冷却隔离保护。

架构设计原则 (ADR-033)

ACCEPTED
  • 网关独占凭据：Browser Publisher 独占公众号 AppID/Secret，负责素材上传与草稿创建，Notify Hub 保持轻量与纯调度；
  • 防风控熔断铁律：严禁任何伪造浏览器指纹或打码平台破解；遇验证码自动暂停并告警，由人工在控制台确认；
  • 两阶段幂等保护：一旦点击发表进入只读 reconcile 流程，绝不重复触发第二次点击。
